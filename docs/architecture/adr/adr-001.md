# ADR-001 — Uso de Worker Service em .NET

## Contexto
O sistema necessita executar continuamente tarefas em background para processamento de emails e impressão automática.

## Decisão
Utilizar um Worker Service em .NET como núcleo do processamento.

## Consequências
- Execução contínua
- Fácil deploy em Linux e Windows
- Integração natural com observabilidade e CI/CD
